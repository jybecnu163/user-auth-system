🛡️跨域问题解决方案

⚠️ 由于浏览器安全限制，直接请求 localhost:11434 会被拦截。推荐以下两种方式之一：

  1. 🔓 禁用浏览器安全策略（最简单） – 复制下面命令并运行，会打开一个无跨域限制的浏览器窗口。
    chrome.exe --disable-web-security --user-data-dir="C:\temp_chrome_dev"
    (Edge 用户将 chrome.exe 替换为 msedge.exe，macOS 使用 open -n -a /Applications/Google\ Chrome.app --args --disable-web-security --user-data-dir="/tmp/chrome_dev")
  2. 🌐 使用本地 CORS 代理 – 运行 npm install -g local-cors-proxy 然后 lcp --proxyUrl http://localhost:11434 --port 8010，再将下方 Ollama 地址改为 http://localhost:8010/api/generate。

✅ 配置正确后点击下方“🔌 测试连接”，显示成功即可开始。
